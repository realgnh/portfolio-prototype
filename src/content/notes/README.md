# Writing a note

Add a Markdown file to this folder, e.g. `my-first-note.md`. The file name becomes the URL (`/notes/my-first-note`).
Start it with this header, then write normally in Markdown (headings, lists, links, code blocks, images):

```
---
title: What I learned evaluating RAG
date: 2026-11-20
summary: One sentence shown on the Notes list.
tags: AI, evaluation
---
```

Put images in `public/images/notes/` and link them as `![Alt text](/images/notes/file.png)`.
Delete the two example notes when you add your own.
